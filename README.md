# HandyNotes_NaigtalTeleports

Adds Manaforge Translocator Network node locations for Naigtal

## Features
- Marks all four translocator nodes on the world map and minimap:
  - Umbral Base Camp
  - Extraction Coast
  - Nexus Port
  - Sporeforge
- Tooltip on hover shows the node name and description

## Requirements
- [HandyNotes](https://www.curseforge.com/wow/addons/handynotes) (required dependency)

## Notes

Requires the "Exterior Manaforge Translocator" questline to be completed in-game before the network nodes are usable.
